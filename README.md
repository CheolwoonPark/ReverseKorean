# 한국어 역재생 발음 생성기

한국어 텍스트를 입력받아 음운론적 규칙을 적용한 역재생 발음을 생성하고, 이를 한글 발음으로 출력하는 React 웹 애플리케이션입니다.

**작성자**: Cheolwoon Park

## 개요

이 프로젝트는 한글 텍스트를 실제 발음의 시간축을 뒤집는 역재생 발음으로 변환하는 도구입니다. 단순히 문자를 뒤집는 것이 아니라, 음운론적 규칙을 적용하여 실제 발음을 역전시킵니다.

## 기능

- 한글 텍스트 입력 및 역재생 발음 변환
- 음성 녹음 및 역재생 기능
- 음운론적 규칙 적용 (초성 'ㅇ' 무시, 이중모음 분리, 유성음화, 7종 종성, 자음동화)

## 설치 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm start
```

브라우저에서 http://localhost:3000 을 열어 확인하세요.

## 변환 알고리즘

1. 텍스트 → 음소 단위 분해 (초성 'ㅇ' 무시, 이중모음 분리)
2. 실제 발음 적용 (음운 변동: 유성음화, 7종 종성, 자음동화 등)
3. 음소 배열 완전 역전
4. 역전된 음소를 한글 유사 발음으로 재조합

## 예시

- "안녕하세요" → "오예사흥어인나"
- "거꾸로" → "오루꺼그"
- "안돼" → "에엑따"

## 음운 규칙 상세

### 구현된 음운 변동 규칙

1. **초성 'ㅇ' 무시**: 소리 없는 초성 'ㅇ'은 분해 시 제외
2. **이중모음 분리**: 
   - ㅑ→ㅣ+ㅏ, ㅕ→ㅣ+ㅓ, ㅛ→ㅣ+ㅗ, ㅠ→ㅣ+ㅜ
   - ㅒ→ㅣ+ㅐ, ㅖ→ㅣ+ㅔ
   - ㅘ→ㅗ+ㅏ, ㅙ→ㅗ+ㅐ, ㅝ→ㅜ+ㅓ, ㅞ→ㅜ+ㅔ
   - ㅟ→ㅜ+ㅣ, ㅢ→ㅡ+ㅣ
3. **유성음화**: 받침 뒤의 ㅎ이 유성음으로 변환
4. **7종 종성 법칙**: 모든 받침을 [ㄱ, ㄴ, ㄷ, ㄹ, ㅁ, ㅂ, ㅇ] 중 하나로 발음
5. **자음 동화**: 
   - 비음화: ㄱ, ㄷ, ㅂ + ㄴ, ㅁ → ㅇ, ㄴ, ㅁ
   - 유음화: ㄴ + ㄹ → ㄹ + ㄹ

## 사용 방법

### 텍스트 변환
1. 한글 텍스트를 입력 필드에 입력
2. "변환하기" 버튼 클릭
3. 변환된 역재생 발음 확인

### 음성 녹음 및 역재생
1. "음성 녹음" 버튼 클릭하여 녹음 시작
2. 원하는 음성을 녹음
3. "녹음 중지" 버튼 클릭
4. 원본 녹음과 역재생된 오디오 확인

## SEO 설정

이 프로젝트는 검색 엔진 최적화(SEO)가 적용되어 있습니다:

### 포함된 SEO 기능
- 메타 태그 최적화 (description, keywords, author 등)
- Open Graph 태그 (소셜 미디어 공유 최적화)
- Twitter Card 태그
- 구조화된 데이터 (JSON-LD Schema.org)
- robots.txt 파일
- sitemap.xml 파일
- 시맨틱 HTML 마크업
- 반응형 디자인 (모바일 친화적)

### 배포 전 설정 필요 사항

1. **도메인 설정**
   - `public/index.html`의 모든 `https://your-domain.com`을 실제 도메인으로 변경
   - `public/robots.txt`의 사이트맵 URL 업데이트
   - `public/sitemap.xml`의 URL 업데이트

2. **구글 서치 콘솔**
   - [Google Search Console](https://search.google.com/search-console)에 사이트 등록
   - sitemap.xml 제출
   - robots.txt 확인

3. **소셜 미디어 설정** (선택)
   - `public/index.html`의 Twitter 핸들(`@your-twitter-handle`) 설정

4. **.htaccess 설정** (Apache 서버인 경우)
   - `public/.htaccess` 파일의 HTTPS 리다이렉트 활성화
   - 실제 도메인에 맞게 수정

## 라이선스 및 사용 규칙

이 프로젝트는 개인 프로젝트이며, 다음 사용 규칙이 적용됩니다.

### ⚠️ 금지 사항

1. **상업적 사용 금지**
   - 본 소프트웨어 및 코드는 어떠한 상업적 목적으로도 사용할 수 없습니다.
   - 유료 서비스나 제품에 포함하거나 판매할 수 없습니다.
   - 소프트웨어를 수익화하거나 상업적 이익을 얻는 데 사용할 수 없습니다.
   - 상업적 사용이 필요한 경우, 저작권자(Cheolwoon Park)의 명시적 서면 허가가 필요합니다.

2. **무단 사용 금지**
   - 저작권 표시 없이 재배포하거나 사용할 수 없습니다.
   - 원작자를 표시하지 않고 사용할 수 없습니다.
   - 코드의 소유권이나 저작권을 주장할 수 없습니다.
   - 수정된 버전도 원본 저작권 표시와 이 제한사항을 유지해야 합니다.

3. **기타 제한사항**
   - 본 소프트웨어는 교육 및 개인 학습 목적으로만 사용할 수 있습니다.
   - 위 규칙을 위반할 경우 법적 조치가 취해질 수 있습니다.

- 교육 목적의 사용 (상업적 목적이 아닌 경우)
